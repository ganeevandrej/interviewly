## Функционал

### Группы вопросов

Пользователь может:

- создать группу;
- задать название и accent color;
- редактировать группу;
- удалить группу;
- видеть количество вопросов в группе;
- открыть группу и посмотреть её вопросы.

### Вопросы

Внутри группы пользователь может:

- создать вопрос и ответ;
- редактировать вопрос и ответ;
- удалить вопрос;
- открыть вопрос для изучения.

### Просмотр вопроса

Сделай отдельный Focus-режим:

- сначала отображается только вопрос;
- по нажатию карточка переворачивается и показывает ответ;
- используй плавную 3D flip-анимацию;
- карточку можно перевернуть обратно;
- показывай текущую позицию, например `3 / 24`;
- можно перейти к предыдущему и следующему вопросу;
- при переходе карточка снова показывает вопрос;
- длинный ответ не должен ломать layout.

### Поиск

Сделай глобальный поиск по:

- названию группы;
- тексту вопроса.

Результаты разделяй на `Группы` и `Вопросы`.

Также добавь поиск по вопросам внутри открытой группы.

## Хранение данных

Храни группы и вопросы в localStorage.

Вынеси работу с localStorage в отдельный storage/persistence слой, чтобы UI-компоненты не обращались к нему напрямую.

### Focus

- номер текущего вопроса;

- редактирование вопроса;

## UI

Настрой собственную MUI theme.

Визуальное направление:

- dark theme;
- тёмный сине-чёрный background;
- blue/purple gradients;
- мягкие glow-эффекты;
- полупрозрачные borders;
- большие border-radius;
- аккуратные shadows;
- хорошая типографика и отступы.

`accentColor` группы используй для небольших визуальных акцентов карточки группы: border, gradient или glow.

Добавь плавные hover/transitions и flip-анимацию карточки вопроса.

Интерфейс должен быть адаптивным для desktop и mobile. На desktop группы отображай сеткой, на mobile — в одну колонку.

Создай понятную структуру компонентов, типов, storage и theme.

После реализации запусти TypeScript check, ESLint и production build и исправь найденные проблемы.
