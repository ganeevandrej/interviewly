# AGENTS.md

## Проект

Interviewly — приложение для подготовки к собеседованиям с помощью групп, категорий и карточек «вопрос → ответ».

## Стек

- Next.js
- React
- TypeScript
- Redux Toolkit
- RTK Query
- Material UI
- Prisma
- PostgreSQL / Supabase

## Код

Пиши простой и читаемый код без преждевременных абстракций.

Разделяй пустой строкой логически разные блоки кода: получение данных, проверки, преобразования, побочные эффекты и возврат результата.

Предпочитай:

```ts
const groups = await getGroups();

if (!groups.length) {
  return [];
}

const result = transformGroups(groups);

return result;
```

Не добавляй пустые строки механически — они должны отражать логическую структуру кода.

## Инструменты и контекст

Используй только инструменты, необходимые для текущей задачи.

Перед вызовом внешнего инструмента или MCP-сервера кратко сообщи:
- что хочешь получить;
- зачем это нужно;
- что изменится, если пропустить вызов.

Дождись моего подтверждения перед вызовом внешнего инструмента.

Не запрашивай через внешний инструмент информацию, которая уже есть в текущем контексте, коде или документации проекта.

После получения большого результата инструмента выдели только информацию, необходимую для текущей задачи. Не возвращайся к полному результату и не запрашивай его повторно без необходимости.

Не запускай браузер, Playwright, browser/computer tools или визуальное тестирование UI без моего явного запроса.

Для проверки изменений по умолчанию используй только необходимые локальные проверки: typecheck, lint и релевантные тесты. Не запускай dev-сервер, полный build или дополнительные проверки без необходимости.
